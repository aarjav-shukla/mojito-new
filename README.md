# Mojito New

Mojito New is a responsive single-page cocktail landing site built with React and Vite. The experience is structured as a smooth scroll journey through the brand story, featured cocktails, about section, creative art section, menu, and contact area.

The project focuses on a polished visual presentation with motion-enhanced interactions powered by GSAP. It is designed as a modern showcase site rather than a traditional multi-page app.

## What’s Included

- Animated hero and navigation experience
- Section-based landing page flow
- Cocktail showcase and menu presentation
- Brand story and art-focused content sections
- Contact section for user engagement
- Responsive layout support for different screen sizes

## Tech Stack

- React 19 for the UI layer
- Vite for fast development and production builds
- GSAP for animations and scroll-driven motion
- @gsap/react for React-friendly GSAP integration
- Tailwind CSS 4 for utility-based styling
- react-responsive for responsive behavior across breakpoints
- ESLint for code quality checks
- gh-pages for GitHub Pages deployment.

## Project Structure

- src/App.jsx: Main page composition and section order
- src/components/: Reusable page sections and layout pieces
- constants/: Shared data used across the site
- public/: Static assets such as fonts, images, videos, and reference files

## Available Scripts

- npm run dev: Start the local development server
- npm run build: Create a production build
- npm run preview: Preview the production build locally
- npm run lint: Run ESLint across the project
- npm run deploy: Build and publish to GitHub Pages

## Local Setup

1. Install dependencies with npm install.
2. Start the development server with npm run dev.
3. Open the local URL shown in the terminal.

## Deployment

This project is configured for GitHub Pages deployment through the deploy script in package.json. The homepage field already points to the published site URL.
